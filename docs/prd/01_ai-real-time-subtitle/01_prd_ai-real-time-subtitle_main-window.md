# AI实时字幕-主窗口

## 1. 页面入口

应用启动后直接显示主窗口。

## 2. 页面权限说明

| 角色 | 访问权限 |
|------|----------|
| 所有用户 | 可查看/可操作全部功能 |

## 3. 页面布局

### 3.1 整体布局说明

主窗口由以下区域组成：
- 标题区域：显示应用名称和简介
- 引擎状态与控制区域：显示当前引擎状态，提供开始/停止按钮
- 操作按钮区域：显示/隐藏字幕按钮和设置按钮
- 状态栏：显示当前应用状态

### 3.2 页面线框图

```
┌────────────────────────────────────────────────────────────────┐
│  🎧  AI 实时字幕 — 自动识别系统声音 (网易云 / 浏览器 / 任意播放器)  │
├────────────────────────────────────────────────────────────────┤
│  引擎: 未启动                                    ▶  开始        │
├────────────────────────────────────────────────────────────────┤
│  [显示 / 隐藏字幕]    [⚙  设置]              [状态栏：就绪]    │
└────────────────────────────────────────────────────────────────┘
```

## 4. 页面功能

### 4.1 标题区域

| 项目 | 说明 |
|------|------|
| 内容 | 应用名称和功能描述 |
| 展示规范 | 居中显示，字体加粗 |

### 4.2 引擎状态显示

| 项目 | 说明 |
|------|------|
| 内容 | 当前识别引擎名称 |
| 默认值 | "未启动" |
| 更新时机 | 识别引擎切换时实时更新 |

**状态清单**：

| 状态 | 触发条件 | UI 表现 | 用户可执行操作 |
|------|---------|---------|-------------|
| 未启动 | 应用刚启动或停止识别后 | 显示"引擎: 未启动" | 点击开始按钮 |
| 本地SenseVoice | 选择本地模式并成功启动 | 显示"引擎: 本地 SenseVoice" | 点击停止按钮 |
| 百度在线 | 选择百度模式并成功启动 | 显示"引擎: 百度在线" | 点击停止按钮 |
| 阿里云在线 | 选择阿里云模式并成功启动 | 显示"引擎: 阿里云在线" | 点击停止按钮 |
| 加载中 | 正在初始化引擎 | 显示"引擎: 启动中..." | 不可重复触发 |

### 4.3 开始/停止按钮

| 项目 | 说明 |
|------|------|
| 默认状态 | 显示"▶  开始" |
| 点击后状态 | 切换为"■  停止" |
| 功能 | 启动或停止语音识别 |

**交互细节**：

| 场景 | 交互处理方式 |
|------|------------|
| 点击开始（本地模式） | 显示"引擎: 启动中..."，加载模型完成后显示实际引擎名称 |
| 点击开始（在线模式） | 检查API配置，配置完整则启动；配置缺失则弹出提示并跳转设置 |
| 点击停止 | 立即停止识别，显示"引擎: 未启动" |

**边界条件**：

- 本地模型不存在时：自动下载模型，显示下载进度
- 网络异常（在线模式）：提示网络错误，建议切换本地模式
- API配置错误（在线模式）：提示错误信息，跳转设置页面

### 4.4 显示/隐藏字幕按钮

| 项目 | 说明 |
|------|------|
| 功能 | 控制字幕悬浮窗的显示与隐藏 |
| 交互 | 点击切换字幕窗口显示状态 |

**交互细节**：

| 场景 | 交互处理方式 |
|------|------------|
| 字幕已显示 | 点击后隐藏字幕窗口 |
| 字幕已隐藏 | 点击后显示字幕窗口 |
| 识别未启动 | 点击后仅显示空字幕窗口，提示"点击主窗口的「开始」启动识别" |

### 4.5 设置按钮

| 项目 | 说明 |
|------|------|
| 功能 | 打开设置对话框 |
| 交互 | 点击后弹出设置对话框 |

### 4.6 状态栏

| 项目 | 说明 |
|------|------|
| 默认内容 | "就绪" |
| 更新时机 | 识别状态变化时更新 |

**状态清单**：

| 状态 | 触发条件 | 显示内容 |
|------|---------|----------|
| 就绪 | 应用启动完成 | "就绪" |
| 启动中 | 正在初始化识别引擎 | "启动中..." |
| 识别中 | 识别引擎正常运行 | "识别中" |
| 错误 | 识别过程中发生错误 | 具体错误信息，4秒后恢复"就绪" |
| 设置已保存 | 设置对话框保存成功 | "设置已保存"，2秒后恢复"就绪" |

## 5. 系统托盘菜单

### 5.1 菜单结构

| 菜单项 | 功能 |
|--------|------|
| 显示主窗口 | 恢复显示主窗口 |
| 显示/隐藏字幕 | 控制字幕悬浮窗显示状态 |
| 退出 | 完全退出应用 |

### 5.2 交互规范

| 菜单项 | 触发条件 | 行为 |
|--------|----------|------|
| 显示主窗口 | 主窗口最小化时 | 恢复主窗口显示 |
| 显示/隐藏字幕 | 任意时刻 | 切换字幕窗口显示状态 |
| 退出 | 任意时刻 | 停止识别，隐藏字幕窗口，退出应用 |

**交互细节**：

| 场景 | 交互处理方式 |
|------|------------|
| 点击系统托盘图标 | 触发"显示/隐藏字幕"操作 |
| 右键点击系统托盘图标 | 显示完整菜单 |
