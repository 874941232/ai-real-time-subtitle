# AI实时字幕-字幕悬浮窗

## 1. 页面入口

点击主窗口「开始」按钮后自动显示，或点击主窗口「显示/隐藏字幕」按钮。

## 2. 页面权限说明

| 角色 | 访问权限 |
|------|----------|
| 所有用户 | 可查看/可操作全部功能 |

## 3. 页面布局

### 3.1 整体布局说明

字幕悬浮窗由以下区域组成：
- 顶部工具栏：包含文字颜色、背景颜色、字体大小调整、关闭按钮
- 内容显示区：显示实时识别的字幕文字
- 尺寸调整手柄：位于窗口右下角，用于拉伸调整窗口大小

### 3.2 页面线框图

```
┌─────────────────────────────────────────────────────────────────┐
│                [A] [▣] [−] [+] [✕]                            │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│                     实时字幕显示区域                             │
│                                                                 │
│                     支持多行显示                                 │
│                     自动换行                                     │
│                                                                 │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

## 4. 顶部工具栏

### 4.1 工具栏按钮说明

| 按钮 | 图标 | 功能 | 提示文字 |
|------|------|------|----------|
| 文字颜色 | A | 打开颜色选择器，调整字幕文字颜色 | 文字颜色 |
| 背景颜色 | ▣ | 打开颜色选择器，调整字幕背景颜色 | 背景颜色 |
| 减小字体 | − | 减小字幕字体大小 | 减小字体 |
| 增大字体 | + | 增大字幕字体大小 | 增大字体 |
| 关闭 | ✕ | 隐藏字幕窗口 | 隐藏字幕窗口 |

### 4.2 文字颜色调整按钮

| 项目 | 说明 |
|------|------|
| 控件类型 | 按钮 |
| 默认状态 | 显示字母"A"，颜色与当前文字颜色一致 |
| 交互 | 点击后打开系统颜色选择器 |

**交互细节**：

| 场景 | 交互处理方式 |
|------|------------|
| 点击按钮 | 打开系统颜色选择器，初始颜色为当前文字颜色 |
| 选择颜色 | 更新字幕文字颜色，按钮显示新颜色 |
| 取消选择 | 保持原有颜色不变 |

### 4.3 背景颜色调整按钮

| 项目 | 说明 |
|------|------|
| 控件类型 | 按钮 |
| 默认状态 | 显示方块"▣"，颜色与当前背景颜色一致 |
| 交互 | 点击后打开系统颜色选择器（支持透明度） |

**交互细节**：

| 场景 | 交互处理方式 |
|------|------------|
| 点击按钮 | 打开系统颜色选择器（支持透明度），初始颜色为当前背景颜色 |
| 选择颜色 | 更新字幕背景颜色，按钮显示新颜色 |
| 取消选择 | 保持原有颜色不变 |

### 4.4 字体大小调整按钮

| 项目 | 说明 |
|------|------|
| 减小字体 | 点击后字体大小减2，最小为14 |
| 增大字体 | 点击后字体大小加2，最大为60 |

**交互细节**：

| 场景 | 交互处理方式 |
|------|------------|
| 字体已达最小值 | 减小按钮禁用或无响应 |
| 字体已达最大值 | 增大按钮禁用或无响应 |

### 4.5 关闭按钮

| 项目 | 说明 |
|------|------|
| 功能 | 隐藏字幕窗口 |
| 交互 | 点击后隐藏窗口，可通过主窗口重新显示 |

## 5. 字幕内容显示区

### 5.1 实时字幕显示

| 项目 | 说明 |
|------|------|
| 内容 | 实时识别的文字内容 |
| 显示方式 | 多行显示，自动换行，居中对齐 |
| 更新时机 | 识别引擎输出新结果时实时更新 |

**交互细节**：

| 场景 | 交互处理方式 |
|------|------------|
| 识别未启动 | 显示提示"点击主窗口的「开始」启动识别" |
| 识别进行中 | 实时显示识别结果，支持部分结果更新 |
| 静音状态 | 保持最后显示的字幕内容 |

**状态清单**：

| 状态 | 触发条件 | UI 表现 | 用户可执行操作 |
|------|---------|---------|-------------|
| 未启动 | 应用刚启动，识别未开始 | 显示提示文字 | 点击主窗口开始按钮 |
| 识别中 | 识别引擎正常运行 | 实时显示字幕内容 | 调整样式、拖动窗口 |
| 静音 | 检测到静音 | 保持最后字幕内容不变 | 等待声音恢复 |

### 5.2 字幕滚动动画

| 项目 | 说明 |
|------|------|
| 触发条件 | 新的完整句子识别完成 |
| 动画效果 | 新内容从下方滑入，旧内容上移消失 |
| 动画时长 | 350毫秒 |

**交互细节**：

| 场景 | 交互处理方式 |
|------|------------|
| 新句子到达 | 触发滚动动画，新句子从下方进入 |
| 动画进行中 | 显示滚动效果，旧内容上移 |
| 动画完成 | 更新显示内容，准备下一次动画 |

**边界条件**：

- 连续快速输入时：前一个动画未完成时，停止当前动画并立即显示最新内容

### 5.3 句子去重机制

| 项目 | 说明 |
|------|------|
| 去重范围 | 最近5条句子 |
| 触发条件 | 新识别的句子与最近5条重复 |
| 行为 | 跳过重复句子，不更新显示 |

**交互细节**：

| 场景 | 交互处理方式 |
|------|------------|
| 句子完全重复 | 不触发滚动动画，保持当前显示 |
| 句子部分重复 | 正常显示新句子 |
| 句子缓冲区满 | 保留最近50条句子，丢弃更早的内容 |

## 6. 窗口交互

### 6.1 窗口拖动

| 项目 | 说明 |
|------|------|
| 触发区域 | 整个字幕内容区域 |
| 操作方式 | 鼠标左键按住拖动 |
| 限制 | 窗口不可拖出屏幕边界 |

**交互细节**：

| 场景 | 交互处理方式 |
|------|------------|
| 鼠标进入内容区域 | 鼠标变为拖动光标 |
| 按住鼠标左键 | 开始拖动模式 |
| 拖动过程中 | 窗口跟随鼠标移动 |
| 释放鼠标左键 | 结束拖动模式 |

### 6.2 窗口拉伸调整大小

| 项目 | 说明 |
|------|------|
| 触发区域 | 窗口右下角尺寸手柄 |
| 操作方式 | 鼠标左键按住拉伸 |
| 最小尺寸 | 宽300，高80 |

**交互细节**：

| 场景 | 交互处理方式 |
|------|------------|
| 鼠标进入尺寸手柄区域 | 鼠标变为双向箭头光标 |
| 按住鼠标左键 | 开始拉伸模式 |
| 拉伸过程中 | 窗口大小跟随鼠标变化 |
| 释放鼠标左键 | 结束拉伸模式，更新显示行数 |

### 6.3 行数自适应

| 项目 | 说明 |
|------|------|
| 计算方式 | 根据窗口高度和字体行高计算可显示行数 |
| 最小行数 | 1行 |
| 更新时机 | 窗口大小变化或字体大小变化时 |

**交互细节**：

| 场景 | 交互处理方式 |
|------|------------|
| 窗口高度增加 | 自动增加显示行数 |
| 窗口高度减少 | 自动减少显示行数 |
| 字体大小增加 | 自动减少显示行数 |
| 字体大小减少 | 自动增加显示行数 |

**边界条件**：

- 窗口高度过小时：至少显示1行，可能需要滚动查看全部内容
- 句子数量少于最大行数：只显示实际句子数量

### 6.4 窗口置顶

| 项目 | 说明 |
|------|------|
| 默认状态 | 窗口始终置顶显示 |
| 行为 | 始终显示在其他窗口之上 |

### 6.5 窗口透明度

| 项目 | 说明 |
|------|------|
| 默认值 | 0.85 |
| 影响范围 | 整个字幕窗口 |

## 7. 配置持久化

### 7.1 字幕样式保存

| 项目 | 说明 |
|------|------|
| 保存时机 | 用户调整样式后立即保存 |
| 保存内容 | 文字颜色、背景颜色、字体大小、透明度 |
| 持久化方式 | 配置文件本地存储 |

**交互细节**：

| 场景 | 交互处理方式 |
|------|------------|
| 调整颜色 | 自动保存到配置文件 |
| 调整字体大小 | 自动保存到配置文件 |
| 下次启动 | 加载上次保存的样式配置 |

### 7.2 窗口位置保存

| 项目 | 说明 |
|------|------|
| 保存时机 | 窗口关闭或应用退出时 |
| 保存内容 | 窗口位置和大小 |
| 持久化方式 | 配置文件本地存储 |

**交互细节**：

| 场景 | 交互处理方式 |
|------|------------|
| 拖动窗口 | 更新窗口位置 |
| 调整窗口大小 | 更新窗口尺寸 |
| 下次启动 | 恢复上次保存的窗口位置和大小 |

## 8. 边界条件

| 场景 | 处理方式 |
|------|----------|
| 字幕内容为空 | 显示提示文字"点击主窗口的「开始」启动识别" |
| 字幕内容超长 | 按窗口宽度自动换行，多行显示 |
| 窗口最小化 | 自动隐藏，通过系统托盘或主窗口重新显示 |
| 系统分辨率变化 | 重新计算窗口位置，确保在屏幕可见范围内 |
| 多显示器环境 | 窗口保持在当前显示器范围内 |
| 窗口被遮挡 | 自动置顶，确保可见 |
