# AI实时字幕-设置对话框

## 1. 页面入口

点击主窗口「⚙  设置」按钮。

## 2. 页面权限说明

| 角色 | 访问权限 |
|------|----------|
| 所有用户 | 可查看/可编辑全部设置项 |

## 3. 页面布局

### 3.1 整体布局说明

设置对话框由以下区域组成：
- 识别设置区域：选择识别模式和语言
- 百度API配置区域：输入百度API密钥，提供测试功能
- 阿里云API配置区域：输入阿里云API密钥，提供测试功能
- 音频设置区域：选择音频设备，设置分块秒数和静音阈值
- 本地模型区域：提供模型检查和更新功能
- 底部按钮区域：取消和保存按钮

## 4. 识别设置

### 4.1 识别模式选择

| 项目 | 说明 |
|------|------|
| 控件类型 | 下拉单选 |
| 默认值 | 本地 SenseVoice (离线无限量，推荐) |
| 选项列表 | 本地 SenseVoice (离线无限量，推荐)、百度在线 (永久免费)、阿里云在线 (每日免费额度)、自动模式 (百度优先，失败回退本地) |

**交互细节**：

| 场景 | 交互处理方式 |
|------|------------|
| 选择本地模式 | 无需额外配置，直接可用 |
| 选择百度模式 | 提示配置百度API密钥 |
| 选择阿里云模式 | 提示配置阿里云API密钥 |
| 选择自动模式 | 优先使用百度，其次阿里云，失败自动切本地 |

**边界条件**：

- 选择在线模式但未配置API密钥：启动时提示配置错误

### 4.2 识别语言选择

| 项目 | 说明 |
|------|------|
| 控件类型 | 下拉单选 |
| 默认值 | 中文 |
| 选项列表 | 中文、英文、自动检测 |

**交互细节**：

| 场景 | 交互处理方式 |
|------|------------|
| 选择中文 | 仅识别中文语音 |
| 选择英文 | 仅识别英文语音 |
| 选择自动检测 | 自动识别语音语言类型 |

## 5. 百度API配置

### 5.1 API Key输入框

| 项目 | 说明 |
|------|------|
| 控件类型 | 文本输入框 |
| 默认值 | 空 |
| 占位符 | "API Key" |

### 5.2 Secret Key输入框

| 项目 | 说明 |
|------|------|
| 控件类型 | 密码输入框（隐藏输入内容） |
| 默认值 | 空 |
| 占位符 | "Secret Key" |

### 5.3 测试百度API按钮

| 项目 | 说明 |
|------|------|
| 功能 | 验证百度API配置是否有效 |
| 交互 | 点击后发起API连接测试 |

**交互细节**：

| 场景 | 交互处理方式 |
|------|------------|
| API Key或Secret Key为空 | 弹出警告提示"请先填写百度 API Key 和 Secret Key" |
| 测试成功 | 弹出信息提示"百度 API Key 有效，连接正常！" |
| 测试失败 | 弹出错误提示，显示具体错误信息 |

**状态清单**：

| 状态 | 触发条件 | UI 表现 | 用户可执行操作 |
|------|---------|---------|-------------|
| 默认 | 页面加载完成 | 按钮可点击 | 点击测试 |
| 测试中 | 点击测试按钮后 | 按钮禁用，显示"测试中..." | 等待测试完成 |
| 成功 | API连接正常 | 恢复按钮状态 | 继续操作 |
| 失败 | API连接失败 | 恢复按钮状态 | 修改配置后重试 |

## 7. 音频设置

### 7.1 输入设备选择

| 项目 | 说明 |
|------|------|
| 控件类型 | 下拉单选 |
| 默认值 | 默认扬声器回采 |
| 选项列表 | 默认扬声器回采 + 系统检测到的音频设备列表 |

**交互细节**：

| 场景 | 交互处理方式 |
|------|------------|
| 系统无音频设备 | 仅显示"默认扬声器回采"选项 |

### 7.2 分块秒数设置

| 项目 | 说明 |
|------|------|
| 控件类型 | 数值输入框 |
| 默认值 | 3.0 |
| 范围 | 1.0 - 10.0 |
| 步长 | 0.5 |

**交互细节**：

| 场景 | 交互处理方式 |
|------|------------|
| 值越小 | 识别延迟越低，但识别可能不完整 |
| 值越大 | 识别更完整，但延迟更高 |

### 7.3 静音阈值设置

| 项目 | 说明 |
|------|------|
| 控件类型 | 数值输入框 |
| 默认值 | 0.010 |
| 范围 | 0.0 - 0.5 |
| 步长 | 0.005 |

**交互细节**：

| 场景 | 交互处理方式 |
|------|------------|
| 值越小 | 静音检测更敏感，容易误判 |
| 值越大 | 静音检测更迟钝，可能错过微弱声音 |

## 8. 本地模型

### 8.1 检查更新按钮

| 项目 | 说明 |
|------|------|
| 功能 | 检查本地模型是否为最新版本 |
| 交互 | 点击后检查模型版本 |

**交互细节**：

| 场景 | 交互处理方式 |
|------|------------|
| 未找到本地模型 | 弹出信息提示"未找到本地模型，首次运行时会自动下载" |
| 发现新版本 | 弹出信息提示，显示本地和远程模型大小，建议更新 |
| 已是最新版本 | 弹出信息提示，显示模型路径和大小 |
| 检查失败 | 弹出错误提示，显示具体错误信息 |

### 8.2 更新模型按钮

| 项目 | 说明 |
|------|------|
| 功能 | 更新本地模型到最新版本 |
| 交互 | 点击后弹出确认对话框，确认后开始下载更新 |

**交互细节**：

| 场景 | 交互处理方式 |
|------|------------|
| 点击更新 | 弹出确认对话框，提示"确定要更新本地模型吗？更新会重新下载整个模型文件（约230MB），可能需要几分钟时间。" |
| 用户确认 | 开始下载模型，显示下载进度 |
| 用户取消 | 关闭确认对话框，不执行更新 |
| 更新成功 | 弹出信息提示"模型更新完成！下次启动时会使用新模型。" |
| 更新失败 | 弹出错误提示，显示具体错误信息 |

**危险操作确认**：

| 操作 | 确认弹窗文案 | 确认按钮 | 取消按钮 |
|------|-------------|----------|----------|
| 更新模型 | "确定要更新本地模型吗？更新会重新下载整个模型文件（约230MB），可能需要几分钟时间。" | "是" | "否" |

## 9. 底部按钮

### 9.1 取消按钮

| 项目 | 说明 |
|------|------|
| 功能 | 关闭设置对话框，不保存任何修改 |
| 交互 | 点击后关闭对话框 |

### 9.2 保存按钮

| 项目 | 说明 |
|------|------|
| 功能 | 保存所有设置并关闭对话框 |
| 交互 | 点击后验证并保存设置 |

**交互细节**：

| 场景 | 交互处理方式 |
|------|------------|
| 保存成功 | 关闭对话框，主窗口状态栏显示"设置已保存" |
| 保存失败 | 弹出错误提示，显示具体错误信息 |

**边界条件**：

- 配置文件写入失败：提示错误信息，保持对话框打开
