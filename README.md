# AI 实时字幕

自动识别电脑系统声音，实时显示字幕悬浮窗。支持本地离线识别和国内在线API识别。

## 功能特点

- 🎧 **自动识别系统声音**：支持网易云、浏览器、视频会议等任意播放器
- 🌐 **多识别引擎**：本地 SenseVoice（离线无限量）、百度语音（永久免费）、阿里云（每日免费额度）
- 🏃 **实时字幕显示**：支持多行显示、自动换行、滚动动画
- 🖱️ **自由调整**：窗口可拖动、拉伸，行数自适应窗口高度
- 🎨 **样式自定义**：支持文字颜色、背景颜色、字体大小调整
- 💾 **配置持久化**：自动保存用户设置，下次启动自动恢复

## 技术栈

- Python 3.10+
- PyQt6
- ONNX Runtime（本地识别）
- soundcard（音频捕获）

## 快速开始

### 环境要求

- Windows 10/11 (64位)
- Python 3.10+

### 安装依赖

```bash
pip install -r requirements.txt
```

### 运行应用

```bash
python main.py
```

### 打包成 EXE

```bash
python -m PyInstaller --windowed --onefile --name "AI实时字幕" --distpath dist main.py
```

## 使用说明

1. 点击「开始」按钮启动识别
2. 字幕悬浮窗会自动显示在屏幕上
3. 可通过字幕窗口顶部工具栏调整样式
4. 点击「设置」按钮配置识别引擎和音频参数

## 识别模式

| 模式 | 特点 |
|------|------|
| 本地 SenseVoice | 完全离线，无需网络，无限量使用 |
| 百度在线 | 永久免费，需配置 API Key |
| 阿里云在线 | 每日有免费额度，需配置 AccessKey |
| 自动模式 | 优先使用百度，其次阿里云，失败自动切本地 |

## API 配置

### 百度语音

1. 登录 [百度智能云控制台](https://console.bce.baidu.com/)
2. 进入「语音技术」创建应用
3. 获取 API Key 和 Secret Key
4. 在设置对话框中填写并测试

### 阿里云语音

1. 登录 [阿里云控制台](https://console.aliyun.com/)
2. 开通「智能语音交互」服务
3. 创建项目获取 Appkey
4. 在设置对话框中填写并测试
